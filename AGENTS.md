# Project agent instructions

Before writing architecture documents, incident reports, technical analyses,
design documents, or compatibility reports, read:

- agent/TECHNICAL_WRITING_POLICY.md
- agent/TERMINOLOGY.md
- agent/ARCHITECTURE_FACTS.md
- agent/SOURCE_POLICY.md

Treat TERMINOLOGY.md as the canonical vocabulary.

Do not add a new accepted term without human confirmation.
Put unconfirmed terms into TERMINOLOGY_CANDIDATES.md.

Before final output, perform a terminology review and list:
- unregistered terms;
- inconsistent names;
- unsupported claims;
- uncertain translations;
- terms that need human confirmation.
